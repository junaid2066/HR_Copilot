# 4–5 Minute Demo Script

Introduce HR Copilot as an agentic HR operations assistant. Show the Streamlit dashboard and explain that the agent chooses specialized tools instead of relying on unsupported LLM answers. Demonstrate: employee search; “Build a team for a Python + machine-learning project”; annual-leave policy retrieval; workforce analytics. Open the execution trace to show agent/tool workflow. Conclude with safety guardrails, tests, Docker deployment, and the distinction between decision support and final human HR decisions.
